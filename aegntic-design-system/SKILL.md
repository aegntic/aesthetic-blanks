# Aegntic Design System — Unified Workflow Plugin

This plugin composes all design/UI/UX skills into a single end-to-end workflow for aesthetic-blanks template creation.

## Skill Inventory (Auto-Loaded)

| Skill | Purpose | Invocation |
|-------|---------|------------|
| `impeccable` | Production-grade frontend interfaces, anti-slop aesthetics | `/impeccable craft\|teach\|extract` |
| `design-taste-frontend` | Anti-slop landing pages, portfolios, redesigns with dials | `/design-taste-frontend` |
| `ui-ux-pro-max` | Searchable design intelligence DB (84 styles, 192 palettes, 74 fonts, 98 UX rules) | `python scripts/search.py "..." --design-system` |
| `ui-styling` | shadcn/ui + Tailwind + Radix component implementation | `/ui-styling` |
| `design-system` | Token architecture, component specs, slide generation | `/design-system` |
| `brand` | Brand voice, visual identity, messaging, asset management | `/brand` |
| `banner-design` | Social/ads/hero banners, 22 styles | `/banner-design` |
| `slides` | Strategic HTML presentations with Chart.js | `/slides` |
| `figma-implement-design` | Figma → production code translation | `/figma-implement-design` |
| `skillui` | Reverse-engineer design systems from live sites (CLI) | `skillui --url ... --mode ultra` |

## Quick Start

```bash
# 1. Extract design system from reference site
skillui --url https://linear.app --mode ultra --out ./design-systems/linear

# 2. Generate design system for new project
python /home/ae/.hermes/skills/ui-ux-pro-max/scripts/search.py \
  "SaaS dashboard minimal dark" --design-system \
  -p "MyApp" --persist --output-dir ./my-project

# 3. Run design taste audit on existing page
/design-taste-frontend teach

# 4. Build component with impeccable craft
/impeccable craft "pricing table with 3 tiers"

# 5. Implement with ui-styling (shadcn/ui + Tailwind)
/ui-styling

# 6. Pre-flight QA
/design-taste-frontend (runs full Pre-Flight Check)
```

## Workflow Phases

### Phase 1: Discover & Extract
- `skillui` — crawl live site / repo for exact tokens, animations, components
- `figma-implement-design` — translate Figma files to code
- `/impeccable teach` — gather project design context

### Phase 2: Design System Generation
- `ui-ux-pro-max` --design-system — comprehensive recommendations with reasoning
- `design-system` — token architecture, semantic layers, component specs
- `brand` — voice, identity, messaging framework

### Phase 3: Component & Page Design
- `design-taste-frontend` — landing/portfolio pages with variance/motion/density dials
- `impeccable craft` — distinctive production-grade components
- `ui-styling` — shadcn/ui implementation with Radix primitives
- `banner-design` / `slides` — marketing assets

### Phase 4: Implementation & QA
- `figma-implement-design` — 1:1 visual fidelity from Figma
- `design-taste-frontend` Pre-Flight Check — 60+ automated validations
- `ui-ux-pro-max` references/pro-rules.md — app UI checklist

## Stack Defaults

- **Framework**: Next.js 15 (App Router, RSC)
- **Styling**: Tailwind v4 (`@tailwindcss/postcss`)
- **Animation**: Motion (`motion/react`, formerly Framer Motion)
- **Components**: shadcn/ui (Radix UI primitives)
- **Icons**: `@phosphor-icons/react` → `hugeicons-react` → `@radix-ui/react-icons`
- **Fonts**: `next/font` self-hosted, `font-display: swap`

## Installation

This plugin lives at `aesthetic-blanks/aegntic-design-system/`. To use in a template:

```bash
# Clone aesthetic-blanks
git clone https://github.com/aegntic/aesthetic-blanks.git
cd aesthetic-blanks

# Copy this workflow into your template
cp -r aegntic-design-system/* your-new-template/

# Install skillui globally
npm install -g skillui
npm install playwright && npx playwright install chromium

# Run design system generation
python /home/ae/.hermes/skills/ui-ux-pro-max/scripts/search.py "your brief" --design-system -p "YourProject" --persist --output-dir .
```

## Skill Loading Order (for agents)

When this workflow is invoked, load skills in this order:
1. `ui-ux-pro-max` (foundation database)
2. `design-taste-frontend` (page-level rules + dials)
3. `impeccable` (component craft)
4. `design-system` (tokens, specs)
5. `ui-styling` (implementation)
6. `brand` / `banner-design` / `slides` (marketing)
7. `figma-implement-design` (if Figma source)
8. `skillui` (CLI, not a skill — available globally)
