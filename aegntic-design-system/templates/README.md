# Template Starter

Use `./scripts/aegntic-design-system init <name> <brief>` to scaffold a new aesthetic-blanks template.

Generated structure:
```
<name>/
├── CLAUDE.md
├── .impeccable.md (after /impeccable teach)
├── design-system/<name>/MASTER.md
├── app/  components/  lib/  public/  scripts/
└── SKILL.md (this workflow)
```
